# Distribution and third-party notices

The repository does not currently declare a redistribution license for NSN's own source. This notice does not grant a license or change ownership. An explicit license decision is required before public package distribution.

The minimal installed profile depends on PyYAML (MIT); optional packages carry their own licenses and notices in their distributions. Semantic deployments must also preserve the selected model's license and attribution. Downloaded benchmark datasets, scoring sources and model weights are not bundled in the NSN wheel. Their pinned provenance and upstream license files are described in `benchmarks/public_eval/pins.json` and the evaluation README. LoCoMo's noncommercial dataset license does not become an NSN source license.

No third-party benchmark accuracy or universal competitor leadership is established by this release candidate.

## Architecture and contracts

`nsn.Runtime(directory, graph=True)` / `nsn.init(directory, graph=True)` opt into relationships. The default SDK remains lexical and graph-free at runtime. No new package dependency, graph server, network request, or background worker is required.

The implementation follows the plan's bounded linked-evidence design. It does not reproduce A-MEM's model-driven note enrichment or claim that algorithm's published results. Legacy `GraphBuilder` co-occurrence records are deliberately not imported as factual relations.

Advanced commands on the returned runtime:

```python
memory = nsn.init("./agent-memory", graph=True)
source = memory.append_event(role="user", content="Alice works for Acme.")
memory.extract_relations(source)
# Alternatively, supply a structured source-backed assertion:
memory.record_relation(subject="Alice", predicate="works_for", object="Acme",
                       event_id=source, span_start=0, span_end=21)
pack = memory.retrieve_pack("Which city hosts Alice's employer?")
```

- `record_relation` requires a same-namespace, noncancelled event and a valid nonempty character span. It records the caller's assertion, not proof that the statement is true.
- Relation kinds are explicit and association. RELATED_TO/ASSOCIATED_WITH/CO_OCCURS are always associations and never traverse as factual predicates.
- `valid_from`/`valid_to` are timezone-aware UTC half-open intervals. `replace=True` closes earlier open versions of the same subject/predicate; out-of-order replacement is rejected rather than guessed.
- Entity names/aliases are normalized by casefolding and whitespace. Aliases can be ambiguous; resolution returns no identity for collisions. Every entity, alias, edge, and support lookup is namespace-scoped.
- Conservative extraction recognizes only `X works for Y.` and `X is located in Y.` It rejects pronouns, uncertain/negated statements, conjunctions, and unrecognized grammar into `unresolved_relationships`. Extraction confidence 0.95 is a heuristic label, not calibrated probability.
- `memory.relationships.add_alias(name, alias, namespace)` and `.traverse(query, ...)` expose advanced control.
- Retrieval options `use_graph=False` and `graph_limits={...}` control individual queries.
- Default bounds: depth 3, 32 nodes, 64 edges, 8 candidates, 25 ms soft deadline, and the context pack's token allowance. Explicit traversal defaults to 256 tokens. Limits, truncation reasons, ambiguous aliases, visited counts, and elapsed time are diagnostic fields.
- Traversal is directed, prevents cycles, uses one SQLite read snapshot, and returns explicit steps rather than inferred conclusions. Required source spans/IDs/identity/timestamps are included in each complete candidate. The pack either includes the whole path or excludes it for budget overflow. XML-sensitive path data is escaped.
- Missing/deleted/cancelled source events cannot support a traversal. Session-restricted retrieval requires source events in that session. Event deletion cleans relationship support and unresolved records even when a legacy connection has foreign keys disabled.

## Limits and next phase

- Structured assertions remain the correctness reference. General language extraction, calibrated confidence, pronoun resolution, arbitrary multi-hop reasoning, and generated-answer evaluation are not provided here.
- Alias matching is deterministic exact-name matching. Traversal is outgoing only; reverse/inverse relations must be explicit.
- The 25 ms deadline is a soft compute bound checked during Python traversal and SQLite VM execution, not a hard OS scheduling/I/O guarantee.
- A SQLite read snapshot is the retrieval consistency boundary. Deletions occurring after that snapshot can only affect a subsequent retrieval.
- Real-model evaluation is optional and asset-dependent. The cached encoder's separate offline evaluation passed (1 passed, 14 deselected in 20.73s); see the Phase 05 addendum. This remains a small development fixture.
- Next: implement only `docs/implementation/07-consolidation.md` when instructed, preserving this migration, source semantics, and traversal bounds. Do not enable graph retrieval by default based on this fixture.

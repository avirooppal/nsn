## Behavior Implemented
1. **Three-line Importable `nsn` Facade**:
   - `nsn.init(directory, default_namespace="default", **kwargs)` initializes and registers a global `Runtime` instance.
   - `nsn.init("")` automatically resolves to default local directory (`./agent-memory`).
   - `nsn.wrap(model, namespace="default", runtime=None, **kwargs)` attaches the model to the runtime.
   - Calling `nsn.wrap(...)` before `nsn.init(...)` produces a descriptive `RuntimeError`.
   - Repeated `init` calls with identical directories return the existing runtime; conflicting directories without `force=True` raise `ValueError`.
   - Double-wrapping prevention: wrapping an already wrapped model returns it idempotently without stacking proxies.
   - Runtime supports context manager syntax (`with nsn.init(path) as runtime:`).
   - `nsn.flush()` and `nsn.close()` provide explicit lifecycle and consistency barriers.

2. **Call Interception Lifecycle**:
   - Query extraction: safely parses strings, dictionary payloads (`input`, `prompt`, `text`), or message lists.
   - Prior evidence retrieval: executes `runtime.retrieve_pack(query)` **before** appending the current user turn to storage. This guarantees the current input is never self-recalled.
   - Input durable capture: atomically appends the user event to SQLite and invokes conservative fact extraction.
   - Delimited evidence injection: prepends the evidence pack to the prompt for text callables, or prepends a system message for OpenAI chat completions, without mutating caller-owned message lists or inputs.
   - Single invocation: transparently delegates to the underlying model. Exceptions are captured to record a failed turn status in SQLite before being re-raised unaltered.
   - Completion logging: captures the assistant's output and logs it as an event with `role="assistant"` and `turn_status="completed"`.

3. **Supported Model Adapters**:
   - **Generic Text Callables**: `Callable[[str], str]` and LangChain `.invoke(...)` models.
   - **Async Callables**: Coroutines and `.ainvoke(...)` models with async turn failure logging.
   - **OpenAI-Compatible Chat Completions**:
     - Non-streaming: intercepts `.chat.completions.create(messages=...)`, injecting memory into a cloned list.
     - Streaming (`stream=True`): returns a `StreamingResponseWrapper` iterator that yields chunks transparently, accumulates delta tokens, and handles stream cancellation cleanly.
   - **Custom Adapter Extension**: accepts custom adapter class via `adapter=...` parameter in `nsn.wrap(...)`.

4. **Minimal Installation & Lazy Imports**:
   - `pyproject.toml` base dependencies reduced to `pyyaml>=6.0`. Heavy ML dependencies (`sentence-transformers`, `faiss-cpu`, `spacy`, `numpy`) moved to optional extra `semantic`.
   - Lazy loading for `Memory`, `NSN`, `faiss`, `spacy`, and retrieval thread pool ensures that importing `nsn` performs zero file writes, zero network calls, zero model loading, and spawns zero background threads.
   - Built standalone wheel `dist/nsn-0.3.0-py3-none-any.whl` packaging both `nsn` and `neurosleepnet`. Verified in an isolated clean virtual environment outside the checkout with none of `numpy`, `faiss`, `torch`, `spacy`, `sentence-transformers` installed.

5. **Streaming Cancellation & Turn Status Integrity**:
   - `StreamingResponseWrapper` tracks `on_complete` (full consumption) versus `on_cancel` (generator closed/cancelled early).
   - Partial/cancelled streams are stored with `turn_status="cancelled"`, never falsely marked `"completed"`.

6. **Context Window Token Budgeting & Overhead Accounting**:
   - `ContextPacker.count_chat_tokens` calculates token usage across user, system, name, and tool call IDs, accounting for per-message formatting overhead (`<|im_start|>{role}...<|im_end|>`) and assistant turn priming.
   - Tool-schema token overhead (`tools` list) is serialized and budgeted directly against available context window space.
   - **Honest Estimation Labeling**: token estimation method is labeled `"estimated"` whenever message or tool formatting overhead is estimated (including raw tokenizers). It is labeled `"exact"` only when using the target model's actual chat template (`apply_chat_template`) or provider-specific chat counter.
   - Reserved output tokens (`max_tokens`, `max_completion_tokens`, or `reserved_output_tokens`) and `input_window_tokens` are strictly enforced. Crowded contexts return diagnostic empty packs (`impossible_token_budget`) rather than overflowing model windows.

7. **Direct `.invoke()` and `.ainvoke()` Memory Interception**:
   - Implemented explicit `.invoke()` and `.ainvoke()` methods on `CallableAdapter`, `AsyncCallableAdapter`, and `NSN`, ensuring direct calls do not bypass memory interception.

8. **NSN-Only Option Consumption & Parameter Preservation**:
   - `extract_nsn_options(kwargs)` cleanly separates NSN-specific per-call options (`input_window_tokens`, `reserved_output_tokens`, `tokenizer`, `namespace`, `auto_observe_inputs`, `auto_observe_outputs`, `as_of_time`, `session_id`, `max_memory_tokens`, `memory_limit`, `budget_breakdown`, `chat_counter`, `adapter`) from underlying model parameters.
   - Legitimate provider parameters (`model`, `temperature`, `max_tokens`, `max_completion_tokens`, `tools`, `tool_choice`, `stream`, `top_p`, etc.) are preserved unchanged and forwarded directly to underlying provider models.
   - Regression tests verify that underlying models with strict signatures lacking `**kwargs` catch-alls (`StrictChatCompletions`, `StrictCallableModel`, `StrictLangChainModel`) execute cleanly without `TypeError`.

9. **Legacy Compatibility**:
   - Calling legacy `nsn.init(model)` issues a `DeprecationWarning` and wraps the model.
   - `neurosleepnet` package exports `init`, `wrap`, `Runtime`, and `NSN` lazily.

## Limitations
- Non-OpenAI streaming chunk formats (e.g. Anthropic SSE raw frames) require using the `adapter=` extension hook if stream delta paths differ.
- Tool-schema token counting parses JSON tool representations and adds an envelope estimate; when an exact tokenizer is supplied, exact counts are computed; otherwise a conservative estimate is clearly labeled as `"conservative_estimate"`.

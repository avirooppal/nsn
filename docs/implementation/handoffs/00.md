# Phase 00 handoff — Repair evaluation integrity

Status: COMPLETE
Revision / working-tree description: Implemented evaluation fairness, preserved question denominator, added generator interface with crash/mock handling, fixed term-based BM25 and ranking, seed propagation, and cleanup of derived index files.
Prerequisites inspected: `plan.md`, `docs/implementation/README.md`, `docs/implementation/00-evaluation-integrity.md`, `benchmarks/runners/evaluator.py`, `benchmarks/metrics/`, `benchmarks/baselines/`.

## Behavior implemented
1. **Preserved Question Coverage and Evidence Denominator**:
   - In `benchmarks/runners/evaluator.py` and `benchmarks/metrics/retrieval.py`, missing or duplicate-rejected gold evidence remains in the denominator (`total_gold_count`). Queries where all gold evidence was rejected are no longer skipped (`dup_skip` records diagnostic counts without discarding questions).
   - Multi-hop / multi-evidence questions requiring N gold IDs now measure recall against N rather than against the subset of successfully translated IDs.
2. **Common Generator Protocol and Crash Handling**:
   - Created `benchmarks/runners/generator.py` with `BaseGenerator`, `MockGenerator`, and `OllamaGenerator`.
   - In `BenchmarkEvaluator._evaluate_query_set`, generator crashes or generation failures now record `failed_questions += 1` and `pred = ""` without silently substituting extractive fallbacks.
   - Retrieval latency (`retrieval_latency_ms`) and generation latency (`generation_latency_ms`) are measured and recorded separately alongside total latency.
3. **Corrected Term-Based BM25 and Clean Baseline Ranking**:
   - Corrected SQLite FTS5 `search_keyword` in `neurosleepnet/storage/sqlite.py` to compile search tokens into term-based queries ordered by `bm25(memories_fts) ASC, m.created_at DESC` with explicit phrase query support (`"..."`).
   - Removed unconditional `<< BEST` marker in `benchmarks/run_head_to_head.py`. Ranking sorts by actual measured metric values and highlights top performers only when verified.
4. **Seed Propagation and Dataset Hashes**:
   - `BenchmarkEvaluator` methods now accept `seed: int = 42`, pass it to `LargeSyntheticDatasetGenerator(seed=seed)` and `system.set_seed(seed)`.
   - Deterministic SHA-256 `dataset_hash` is recorded with each benchmark run.
   - Fixed missing multihop query append bug in `LargeSyntheticDatasetGenerator.generate_gold_graph_multihop_dataset`.
5. **Comprehensive Artifact Cleanup**:
   - Baseline systems (`bm25`, `dense_rag`, `hybrid_rag`, `nsn_adapter`) now cleanly purge `-wal`, `-shm`, `_hnsw.faiss`, `_ivfpq.faiss`, and `.faiss_ids` files on reset.

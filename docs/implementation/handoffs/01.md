# Phase 01 handoff — Scoped durable storage and runtime ownership

Status: COMPLETE
Revision / working-tree description: Implemented transactional schema migrations, strict namespace isolation on all read/delete/search/list operations, scoped event repository, durable outbox jobs with leases, and backup of legacy databases.
Prerequisites inspected: `docs/implementation/handoffs/00.md`, `neurosleepnet/storage/sqlite.py`, `neurosleepnet/memory/schemas.py`.

## Behavior implemented
1. **Schema Versioning & Migrations (`neurosleepnet/storage/migrations.py`)**:
   - Versioned migrations (`schema_migrations` table) with idempotent execution.
   - Automatic `.bak` snapshot created when an unmigrated legacy database is first opened.
   - Rejection with clear `ValueError` when an unsupported future schema version is encountered.
2. **Authoritative Event Store**:
   - `events` table with explicit UTC timestamps, `namespace`, `session_id`, `role`, `content`, `source_identity`, `event_time`, `turn_status`, `idempotency_key`, and `retention_policy`.
   - `events_fts` virtual table for term-based FTS5 BM25 search over scoped events.
   - `append_event`, `get_event`, `delete_event`, `list_events`, `search_events` enforce namespace scoping on every query.
   - Scoped idempotency prevents duplicating exact repeats within the same namespace while allowing identical content across distinct namespaces.
3. **Durable Outbox Queue & Leases**:
   - `jobs` table storing `id`, `namespace`, `job_type`, `payload`, `status`, `attempts`, `max_attempts`, `leased_by`, `lease_expires_at`.
   - Atomic commit of event and outbox job in a single database transaction.
   - Leased jobs with expiration timeouts protect against worker crash/duplicate execution.
   - Worker completion (`complete_job`) and failure tracking (`fail_job`) with status transition to `failed` upon reaching `max_attempts`.
4. **Lifecycle & Concurrency (`flush` and `close`)**:
   - SQLite WAL mode and busy timeout (`busy_timeout=5000`) enabled for safe concurrent access.
   - `flush()` checks outbox settlement and reports `False` if any job failed permanently.
   - `close()` is idempotent.
5. **Enforced Scope on Legacy APIs**:
   - `get`, `delete`, `list`, `store_graph_node`, `store_graph_edge`, `get_graph_node`, `query_graph` now support and enforce namespace filtering.

## Contracts and decisions
- `append_event(event_dict, outbox_jobs=None)`: returns `event_id`. Requires `namespace` field.
- `get_event(event_id, namespace)`: returns event dict or `None`.
- `delete_event(event_id, namespace)`: returns `bool`.
- `flush(timeout_seconds=5.0)`: returns `bool` (`False` if unhandled failures or unsettled jobs).

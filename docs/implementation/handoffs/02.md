## Key Decisions
- **Fact Schema**: Explicit `valid_from` and `valid_to` temporal intervals alongside `recorded_at` system time (bitemporal capability).
- **Conflict Resolution**: Contradictory assertions from sources of equal authority are not arbitrarily broken by "last write wins". Both are assigned `status='disputed'` and linked under a common `conflict_group`.
- **Cardinals vs Sets**: Distinguish single-valued properties from set-valued lists (e.g. `allowed_users`). Sets append unique elements idempotently.
